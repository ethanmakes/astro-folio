## 关于 Folio

Folio 是一款使用 Astro 构建的博客主题，核心理念是简洁与快速。它基于上游主题 [astro-gyoza](https://github.com/lxchapu/astro-gyoza) 重构而来：保留了原有的设计与页面结构，技术栈升级到 Astro 7 与 Tailwind CSS 4，并移除了全部 React 运行时，所有组件均由 Astro 组件与原生脚本实现。

主题内置全文搜索（pagefind）、明暗双色模式、页面切换动画、分类与标签、归档、项目与友链页面，适合用来搭建个人博客。

- 在 [Markdown 语法展示](/posts/markdown) 中可以预览文章的渲染效果
- 可以前往 [欢迎使用 Folio](/posts/guide) 了解安装与配置方法
